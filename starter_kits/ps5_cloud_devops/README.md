# ☁️ Cloud & DevOps Starter Kit — PS5: "Deploy It Live"

## 📁 Repository Structure
- `deployable_app/backend/`: Node.js Express REST API (`server.js`, `package.json`).
- `deployable_app/frontend/`: Single-Page Application (`index.html`).
- `deployable_app/database/`: SQL schema script (`schema.sql`).
- `deployable_app/.env.example`: Environment variables template.
- `deployable_app/Dockerfile`: Production Docker container configuration.

## 📝 Candidate Deliverables (2 Hours)
1. **Host Live Frontend & Backend:** Host and deploy the complete web application to public cloud platforms/services of your choice (static hosting for Frontend, container/PaaS cloud host for Backend, managed cloud database for Database).
2. **Configure CORS & Env Secrets:** Connect Frontend to Backend without CORS or SSL errors. Use platform environment variable configuration (do NOT commit secrets to GitHub).
3. **Clean Version Control:** Ensure `.gitignore`, `.env.example`, clean commit history, and setup instructions are present in your public code repository.
4. **Working Live URL:** Provide public HTTPS URLs where evaluators can test the application live from any device.
