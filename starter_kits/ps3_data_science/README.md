# 📊 Data Science Starter Kit — PS3: "Find Something We Don't Know"

## 📁 Included Files
- `student_activity_data.csv`: Anonymized activity dataset containing 2,000 student records across 5 academic departments.
- `generate_dataset.py`: Reproducible Python dataset generator script.

## 📝 Candidate Instructions
1. Load `student_activity_data.csv` into your Jupyter Notebook or Python environment (`pandas`, `numpy`, `matplotlib`/`seaborn`, `scikit-learn`).
2. Perform Exploratory Data Analysis (EDA), clean missing/outlier entries, and formulate hypotheses regarding student behavior and academic outcomes.
3. Discover **at least 2 non-trivial insights or patterns** backed by statistical evidence or data visualizations.
4. Prepare your notebook and be ready to present your findings during the 15-minute viva.
