## 📌 Instructions for Candidates

1. **Step 1: View Problem Statements**
   - Open **`CANDIDATE_PROBLEM_STATEMENTS.xlsx`** (or `.csv`) to review the 6 domain problem statements.
   - Choose **1 Problem Statement** corresponding to your preferred domain.

2. **Step 2: Locate Your Starter Kit**
   - **Domain 1 (AI / Gen AI):** [`starter_kits/ps1_ai_genai/`](starter_kits/ps1_ai_genai/)
   - **Domain 2 (Full Stack Dev):** Build your solution from scratch or your preferred web boilerplate.
   - **Domain 3 (Data Science):** [`starter_kits/ps3_data_science/`](starter_kits/ps3_data_science/)
   - **Domain 4 (Cybersecurity):** [`starter_kits/ps4_cybersecurity/`](starter_kits/ps4_cybersecurity/)
   - **Domain 5 (Cloud / DevOps):** [`starter_kits/ps5_cloud_devops/`](starter_kits/ps5_cloud_devops/)
   - **Domain 6 (Mobile App Dev):** Build your solution from scratch or your preferred mobile framework.

3. **Step 3: 2-Hour Challenge Execution**
   - Read the `README.md` file inside your domain's starter kit directory.
   - Work on your solution for **2 Hours**.
   - Create a `DECISIONS.md` file in your repository documenting your problem understanding, architectural choices, and trade-offs.

4. **Step 4: Submission**
   - Push your code to a public GitHub repository.
   - Provide your public GitHub link and live demo URL (if applicable) to the evaluators.

*Good luck to all candidates! Focus on Problem Understanding, System Architecture, and Clean Decision-Making.*
